# Newton 1.0 scope and Definition of Done

## Included

- Windows, WPF and Evergreen WebView2
- Dedicated address bar and separate search field
- Horizontal and vertical tabs, groups, workspaces and split view
- Sleeping/discarded tabs and session recovery
- History, bookmarks and downloads
- Profiles and genuinely isolated private browsing
- Central permissions, provider choice and local suggestions
- Basic, accurately described tracking protection
- Themes, keyboard accessibility and reliable signed updates

## Explicitly deferred

- macOS, Linux and mobile production releases
- Chromium fork, extension marketplace and full Chrome-extension compatibility
- Cloud sync ecosystem, VPN, AI agents and proprietary search
- Email, calendar, wallet or advertising products

## Definition of Done

A v1 feature is Verified only when its implementation, automated tests, documentation, architecture checks, accessibility checks, security/privacy review, error handling, migration/recovery handling and required manual QA are complete. Newton 1.0 Stable cannot be declared while signed automatic updates, private browsing, core data interfaces, accessibility evidence, compatibility evidence or critical security findings remain unresolved.
